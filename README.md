# G3rtPB87_Dev

A collection of personal development projects — full-stack web apps, data analysis notebooks, and utility scripts, mostly built with Django, FastAPI, and Python.

## Projects

| Project | Description | Stack |
|---|---|---|
| [ecommerce_project](ecommerce_project) | "GB's Online Market" — Django eCommerce app with buyer/vendor roles, store & product management, and a session-based shopping cart. | Django |
| [news_application](news_application) | News platform for independent journalists and publishers, with role-based user management, reader subscriptions, and automated content dissemination. | Django |
| [nexus_logs](nexus_logs) | Self-hosted workflow tracker for an electrician's daily jobs — imports Google Maps Timeline exports, logs parts/comments per site visit, and exports to CSV/XLSX. | Django, SQLite, Docker |
| [smarge_ai](smarge_ai) | SmargeAI — a conversational AI agent platform powered by Google Gemini, with JWT auth, streaming responses, and a React chat UI. | FastAPI, React, LangChain |
| [table_changelog](table_changelog) | Audit-trail system for SQL Server that captures INSERT/UPDATE/DELETE changes on a table as JSON snapshots, with a Streamlit UI for browsing and replaying changes. | Streamlit, SQL Server, SQLite |
| [sticky_notes](sticky_notes) | Simple Django CRUD app for creating, editing, and deleting personal notes, built as an MVT/testing demo. | Django |
| [report_examples](report_examples) | Exploratory data analysis notebooks and reports (regression, decision trees, EDA) covering datasets like Ames housing, Titanic, diabetes, and insurance. | Jupyter, pandas, scikit-learn |
| [apis](apis) | Miscellaneous API test payloads and a SQL Server usage-metrics script. | JSON, T-SQL |

## Getting started

Each project directory is self-contained and has its own setup instructions — see the README inside that folder (where one exists) for install and run steps.
